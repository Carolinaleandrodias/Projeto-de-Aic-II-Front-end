>>>>O QUE É BLUEPRINT<<<<<<
Blueprints são uma forma de modularizar a aplicação, ou seja, dividir o projeto em partes menores e organizadas, o que facilita o desenvolvimento e a manutenção.
Elas permitem definir rotas, formulários, configurações e outras funcionalidades de forma independente, sendo depois "registradas" na aplicação principal.


/// ARQUIVOS ATÉ AGORA DENTRO DO APP ///


init.py 

> inicializar a aplicação e configurar o ambiente para que os outros módulos e componentes funcionem de maneira integrada
> Arquivos de Login
LoginManager: Configura o gerenciamento de login e autenticação de usuários através do Flask-Login.
login_manager.login_view: Define a rota de login (usuarios.login), que é para onde usuários não autenticados serão redirecionados se tentarem acessar uma rota protegida.
load_user: Função usada para carregar os dados de um usuário a partir de seu user_id. Isso permite que o sistema de login saiba qual usuário está atualmente autenticado.

>Blueprints 

Cada blueprint é associada a um "prefixo de URL" para acessar rotas específicas, como:
/usuarios: Gerenciamento de usuários (login, perfil)
/reservas: Funcionalidades de reserva
/salas: Gerenciamento de salas


models.py:
Define os modelos de dados para o banco de dados, utilizando o SQLAlchemy do Flask. Esses modelos correspondem às tabelas do banco de dados e definem as propriedades dos objetos e como eles serão armazenados e manipulados.

Componentes:
Reserva: Representa uma reserva de sala. Contém informações como a sala reservada, o usuário que fez a reserva, e o horário de início e fim da reserva.
Sala: Representa as salas disponíveis para reserva. Contém informações como o número da sala e sua capacidade.
Usuario: Representa os usuários da aplicação. Contém informações como e-mail, nome, senha e tipo (se é um 'professor', 'aluno' ou 'admin').
O SQLAlchemy está sendo usado aqui para mapear as tabelas do banco de dados (como Reserva, Sala, Usuario) e criar as interações necessárias com essas tabelas.


reservas.py 

Define o blueprint de reservas, onde são configuradas as rotas e ações relacionadas às reservas de salas. Ele importa o modelo Reserva para interagir com as reservas no banco de dados.
Componentes:
Reserva: A classe que mapeia a tabela de reservas no banco de dados.
Sala: A classe que mapeia a tabela de salas no banco de dados.
Usuario: A classe que mapeia a tabela de usuários.
Rotas:
/reservar: Rota para realizar uma nova reserva. Verifica se a sala está disponível para o horário desejado.
/consultar: Rota para consultar todas as reservas.
/minhas_reservas: Rota para o usuário ver as suas próprias reservas.
/cancelar_reserva/<int:id>: Rota para o usuário cancelar uma reserva específica, verificando se o usuário logado é o responsável pela reserva.

routes.py 
 É blueprint principal do projeto, com as rotas básicas que lidam com o login, logout e consulta das reservas.

Componentes:
main: Blueprint principal que gerencia as rotas gerais da aplicação.
Rotas:
/: Página inicial do site.
/login: Rota de login para os usuários. Verifica as credenciais de e-mail e senha e realiza a autenticação com Flask-Login.
/logout: Rota de logout que desconecta o usuário atual.
/reservar: Rota para realizar uma nova reserva de sala.
/consultar: Rota para consultar as reservas feitas.
/minhas_reservas: Rota para consultar as reservas feitas pelo usuário logado.
/cancelar_reserva/<int:id>: Rota para o usuário cancelar uma reserva.

salas.py 

É o blueprint de salas, gerenciando as rotas relacionadas ao cadastro e edição de salas disponíveis para reserva.

Componentes:
salas: Blueprint responsável pelas rotas de gerenciamento de salas.
Rotas:
/: Rota para listar todas as salas cadastradas no sistema.
/adicionar: Rota para adicionar uma nova sala ao sistema. Só administradores podem acessar essa rota.
/editar/<int:id>: Rota para editar uma sala existente.
/excluir/<int:id>: Rota para excluir uma sala existente. Também restrita a administradores.

usuarios.py 

O blueprint de usuários, gerenciando o login, perfil e autenticação dos usuários. Também define o modelo de dados Usuario, responsável pela tabela de usuários no banco de dados.

Componentes:
usuarios: Blueprint responsável pelas rotas relacionadas ao gerenciamento de usuários.
Modelo Usuario: Define a tabela de usuários no banco de dados com campos como e-mail, senha, nome e tipo (usuário ou administrador).
Rotas:
/login: Rota de login onde o usuário insere suas credenciais para autenticação.
/perfil: Rota para exibir o perfil do usuário logado.


forms.py
 Define três formulários diferentes usando a biblioteca Flask-WTF, que permite gerenciar e validar formulários HTML de maneira mais eficiente no Flask.

1. ReservaForm
Este formulário é utilizado para criar reservas de sala, coletando dados essenciais sobre a reserva, como:

sala_id: Campo de seleção (SelectField) para o ID da sala, com validação obrigatória. Esse campo recebe as opções de salas disponíveis.
inicio: Campo de data e hora (DateTimeField) para o horário de início da reserva, com validação obrigatória.
fim: Campo de data e hora (DateTimeField) para o horário de término da reserva, também obrigatório.
Validação personalizada (validate_fim): Impede que o horário de término (fim) seja anterior ou igual ao horário de início (inicio), garantindo que a reserva tenha uma duração válida.
submit: Botão para enviar o formulário.
